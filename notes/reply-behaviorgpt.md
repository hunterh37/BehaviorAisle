# Is Behavior Aisle calling BehaviorGPT for real

Partly. The call is real when the local proxy runs. Most of what the demo shows comes from app-side code.

## Wiring

1. Each shopper step builds a `PredictionRequest` (persona, history, cart, catalog).
2. `RoutedPredictor` (BehaviorAisle/Predict/BehaviorGPTPredictor.swift:78) picks a source by mode:
   - `live`: POST to the proxy. On success the result is logged to Documents/predictions.jsonl.
   - `replay`: look up a logged result by persona + last 4 events.
   - `heuristic`: `HeuristicPredictor.swift`, a hand-written softmax (category affinity, price, promo, eye level, distance).
   - Live failure falls back to replay, then heuristic. The panel shows `heuristic (live failed)`.
3. Defaults (BehaviorAisle/Model/AppModel.swift:20): simulator = `live` at `http://127.0.0.1:8787/predict`;
   device = `heuristic` with an empty proxy URL. On a Vision Pro, nothing calls BehaviorGPT unless a proxy URL is typed in Settings.
4. The proxy (`proxy/server.mjs` locally, `proxy/worker.js` for Cloudflare) holds the Unbox API key and calls
   `https://portal.unboxai.com/api/v1/shop/recommend` with `catalog_id cat_aad381c2766331790c3efaa8`, `kind: for_you`
   (proxy/core.mjs:14). The catalog was uploaded with `tools/embed_catalog.py`.
5. If the proxy is not running, every simulator step silently becomes the heuristic.

## What BehaviorGPT contributes

- Input it receives: up to 19 past items as `view` events (add_to_cart is sent as view too) plus the cart as one `order`.
  No shelf position, aisle, distance or sign.
- Output: a ranked list of 8 item ids, no probabilities.
- The proxy invents the probabilities: fixed rank priors `[0.32, 0.22, 0.15, ...]`, times 1.8 if on sale,
  times 1.15 if eye level, plus a `checkout` row from cart fill (proxy/core.mjs:21-35). Action labels
  (view vs add_to_cart) are also proxy rules.
- So in live mode the item ordering is BehaviorGPT; the percentages, the sale effect, the eye-level effect and
  when the shopper checks out are app logic.
- Anomaly score = share of cart items BehaviorGPT did not rank, times 0.5. Also proxy-made.

## Parts that never touch BehaviorGPT

- Heatmap (Viz/HeatmapLayer.swift:29) uses `HeuristicPredictor` directly.
- Experiments and the accuracy/what-if numbers in the PDFs (Predict/Experiment.swift:143-200) use only
  `HeuristicPredictor`, scored against trips generated by the same heuristic.
- Personas are synthetic, so BehaviorGPT gets cold-start histories.

## How to see it live

```
node proxy/server.mjs   # 127.0.0.1:8787, reads UNBOXAI_API_KEY from ~/.config/behavioraisle/env
```
Run in the simulator; the intent panel source tag reads `behaviorgpt`. Anything else (`replay`, `heuristic`,
`heuristic (live failed)`) means the model was not called for that step.
